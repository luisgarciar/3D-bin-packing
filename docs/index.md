# 3D Bin Packing Documentation

This site contains project documentation for the 3D bin packing environment.

## Contents

- **State, Action, and Reward Definition**: formal description of the environment interfaces.

## Local usage

Use `uv` to run the docs locally:

```bash
uv sync --extra dev
uv run mkdocs serve
```

Build the static site:

```bash
uv run mkdocs build --strict
```
